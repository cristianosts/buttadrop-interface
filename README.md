### Buttadrop Interface

Aplicação web construída para oferecer uma experiência digital fluida e responsiva, com foco em usabilidade e design moderno.
### 🛠️ Tecnologias Utilizadas
- **React.js**
- **Next.js**
- **Tailwind CSS**
- **TypeScript**
- **UX Design**

### 📂 Estrutura do Projeto
- `src/components/` → Componentes reutilizáveis
- `src/pages/` → Páginas principais
- `src/styles/` → Configurações de estilo com Tailwind

### ⚙️ Instalação
Clone o repositório e instale as dependências:
```bash
git clone https://github.com/cristianosts/buttadrop-interface.git
cd buttadrop-interface
npm install
